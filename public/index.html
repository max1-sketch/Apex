Roblox Moderation Setup

How Roblox bans are enforced in this project
🔌 MessagingService + Lua Handler
Actions are published from this dashboard to your live Roblox servers over MessagingService, and carried out by ApexAdminHandler.lua in ServerScriptService.
  • Real-time delivery to live servers
  • Supports bans, unbans, kicks, mutes, and unmutes
  • Requires the game script to be installed and the game published
Ban enforcement uses Roblox's native Players:BanAsync() / UnbanAsync() API inside that script — not a third-party ban list.
